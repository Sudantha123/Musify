# Musify

Lightweight Android music client starter built with Kotlin and Jetpack Compose.

- Package: `com.sudantha.musify`
- UI: Home, Search, Library, mini-player
- XML vector launcher icon
- GitHub Actions builds `Musify.apk` and uploads artifact `Musify`

## Build
Workflow: Actions → Build Musify APK. The downloadable APK is under the successful run's Artifacts section.

## Scope
The current version uses local demo tracks. Live YouTube Music search, account sync, thumbnails from a remote catalog, and authorized audio-provider playback are not connected yet. It does not implement private stream URL extraction or access-control bypass.
